# BOX Integration Systems — nueva web corporativa

Proyecto independiente de la web anterior. La web estática se encuentra en `boxis-web-nueva.zip`; el flujo de GitHub Actions la extrae y publica mediante GitHub Pages.

Para actualizarla, sustituye el ZIP por una nueva versión conservando la carpeta `boxis-web-nueva/` en su interior y realiza un nuevo commit en `main`.
